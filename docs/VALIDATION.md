## 核心测试覆盖

- 同日和跨午夜时段，包含开始、排除结束，跨月/跨年。
- 时刻格式错误、开始结束相同、配置损坏、错误数据类型。
- 恰好 60 秒发出一次请求，不堆叠倒计时。
- 延期 60 秒后重新给予完整 60 秒；**短暂主线程卡顿不会提前结束延期**。
- 暂停当前时段、午夜后保持暂停、下一轮自动恢复、持久化重启。
- 设置变更、停止保护、时段结束取消等待中的请求。
- 休眠 / 事件循环中断 / 系统时钟变化后重新提供倒计时宽限。
- 原子写入失败不覆盖旧配置；豁免写入失败不谎报成功。
- 中英文文案键一致、placeholder 完整匹配、空格/标点要求、语言切换保留编辑状态。
- Escape / 关闭按钮不能偷偷跳过正式倒计时；预览可以正常关闭。
- 演示不修改自启、不真实关机；预览不写入当天暂停状态。
- 关机请求工作线程、失败提示、失败后不自动循环请求权限。
- 各平台请求命令不带提权或强制关机参数。
- 更新版本比较、非稳定版本排除、恶意/错误发布页 URL 拒绝、缺失仓库不联网、无配置和网络错误反馈。

本地 Linux 包基于 **Ubuntu 24.04** 构建，不能因为源码在 Linux 上运行就声称二进制兼容所有发行版。CI 的 Linux 构建基线是 Ubuntu 22.04，与本地包不同。

## 推荐的原生验收清单

1. 在目标系统以普通用户运行，确认首次打开不会关机，预览不会产生系统动作。
2. 设置一个即将开始的短时段；先保存所有工作，再在测试机上验证正常关机。
3. 检查自启开启、关闭和移动安装路径后的行为；重新登录验证后台无窗口/无托盘。
4. 验证弹窗、延期、两种 placeholder、跨午夜豁免和重启恢复。
5. 拒绝系统授权，确认可见错误且不会陷入权限弹窗循环。
6. 检查锁屏、睡眠恢复、手动改时区、夏令时切换与时段结束。
7. 在真实公开测试仓库创建稳定 Release，验证检查更新和发布页跳转，再配置正式发布仓库。
